## Hi there 👋

プロダクトの持続的な成長を支えるシステムアーキテクチャ刷新と、自律的な開発組織の構築を行っています。
29年のキャリアを通じ、新規立ち上げから大規模なレガシーシステムの解体・再設計、EM/VPoEとしての組織デザインまで幅広く主導してきました。

---

### 🎯 Core Competencies

* **Architecture & Renewal:** 成長の停滞したレガシー/FAT化システムの解析、モダンアーキテクチャ（DDD / クリーンアーキテクチャ）への段階的刷新
* **Development Process & QA:** 状況に応じた開発フローの再設計、テスト自動化（CI/CD）および品質保証（QA）体制の構築
* **Organization & Strategy:** 経営目標と現場を接続する技術意思決定、プロダクトマネジメントを兼ねた開発交通整理、エンジニア採用・育成
* **Modern Practice:** AI駆動開発（Copilot/LLM活用）による開発プロセスの効率化、最新技術の検証・導入
